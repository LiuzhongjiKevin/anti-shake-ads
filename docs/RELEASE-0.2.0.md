# 0.2.0 测试版

下载 `anti-shake-ads-0.2.0-test.apk` 安装，另外两个 APK 仅用于模拟跳转测试。

- 新首页突出一个大按钮：开启、关闭或恢复保护；应用选择与规则放入次级入口。
- 引导开启无障碍、常驻通知，并提供小米/Redmi/POCO 自启动、省电策略与后台任务锁定说明；附华为 EMUI 入口。
- 新增常驻状态通知，可暂停一分钟或关闭保护；断开无障碍时提示修复。开机/升级后按原有开启状态尝试恢复。
- 修复 Android 15 应用切换动画期间短暂无应用窗口导致漏返回的问题；最多等待 1.5 秒确认窗口，期间不执行返回。
- 新增自适应桌面图标。保留本地处理、不联网的设计。

## 第一次使用

1. 点击“开启保护”，选择高德地图等需要保护的应用。
2. 根据引导，在系统的无障碍服务中打开“反摇一摇广告 · 跳转保护”，再返回本应用。
3. 后台设置中允许通知。澎湃 OS 建议允许后台自启动、省电策略设为“无限制”，并在最近任务中锁定。
4. 从桌面照常打开高德等应用。仅在进入所选应用后的保护时限内处理跨应用跳转。

普通应用无法替你静默开启无障碍、自启动或受限设置。这些步骤必须在系统页面手动确认。常驻服务不保证永久存活，也不是 VPN，不接管网络。
