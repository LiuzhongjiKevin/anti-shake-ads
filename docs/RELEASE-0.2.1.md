# v0.2.1-test · 保护应用一键全选

- 在“选择保护应用”的搜索框下方新增“一键全选”。点击后选中全部可保护应用，包括搜索暂时隐藏的项目。
- 全选后仍可点选单个应用取消；点击“保存”才生效，取消或返回保留原设置。
- 系统设置、桌面、输入法等仍按现有规则排除。允许跳转目标列表保持逐项选择。

## 使用

打开首页的应用管理入口 → 一键全选 → 按需取消个别应用 → 保存。

全选扩大保护范围。正常登录、支付或分享受影响时，可暂停一分钟或配置允许跳转目标。

## 安装

下载 `anti-shake-ads-0.2.1-test.apk` 安装。测试版采用 debug 签名，如提示签名冲突，需要卸载旧版再安装；这会清除设置，需重新授权。
